# PRISM 기존 학습의 문제점과 개선 방향 (쉬운 설명, 2026-09-23)

## 한 줄 요약

가장 중요한 발견은 "용량(부품 수)을 줄이는 안전장치가 우리가 지키고 싶은 성능(개인차·알츠하이머 복원)을 보호하지 못했다"는 점이다. 연습 단계의 학습이 모델 실력(공유 가중치)까지 흔들었을 가능성이 크고(인과는 아직 미확인), 전체 점수(NLL)는 괜찮아 보여도 개인차·알츠하이머 점수가 크게 떨어졌다. RLT가 단독 원인일 가능성은 낮지만 부품 선택 학습과의 상호작용은 배제하지 못했다. E52의 구획(수상돌기 모사) 비선형 부품은 현재 checkpoint·지표에서 기여가 작았다. 이것이 E52 모델 전체가 무의미하다는 뜻은 아니다.

## 1. 배경: 부품(생성자) 줄이기 3단계

- 모델에는 부품(생성자)이 414개 있다. 목표는 꼭 필요한 것만 남기는 것이다.
- 1단계 연습(shadow, E37-40): 실제 답은 414개를 다 써서 내고, 옆에서 "몇 개 빼면 어떨까"를 몰래 시험한다.
- 2단계 볼륨 줄이기(soft, E41-44): 부품의 소리를 조금씩 줄인다.
- 3단계 진짜 끄기(hard, E45 이후): 부품을 실제로 끈다.
- 안전장치: "부품을 뺀 버전의 점수가 다 켠 버전보다 1% 넘게 나빠지면 벌점."

## 2. 문제점

### 문제 1. 연습만 해야 하는데 진짜 실력이 망가졌다

- 연습 단계에서는 "어떤 부품이 중요한가"만 배워야 한다.
- 그런데 실제 코드에서는 연습 결과가 모델의 실력(공유 가중치: 인코더, 디코더, 기본값)까지 바꿨다.
- 비유: 모의고사에서 "문제 1/3을 가리고 풀기" 연습을 하다가, 가린 상태 점수에 매달려 푸는 방법 자체를 바꿔 버린 학생. 가리지 않은 진짜 시험 점수까지 떨어졌다.
- 증거: 연습 단계에서는 본 예측이 부품 414개를 모두 쓰는데도, E39-E40에 본 예측 점수가 크게 나빠졌다(검증 NLL 0.566 → 0.820 → 1.209).

### 문제 2. 벌점이 지나치게 셌다

- 1% 선을 넘는 순간 벌점이 원래 공부(재구성)보다 수십에서 수백 배 크게 걸렸다.
- 비유: 1분 지각에 벌점 100점을 주면 학생은 공부를 제쳐 두고 지각 안 하는 데만 매달린다.
- 증거: E39 중간(약 10,000번째 배치)에 1% 선을 처음 넘은 바로 그 순간부터 무너지기 시작했다. 그 전 2.5에폭 동안은 부품 기대 개수가 414에서 267로 줄어도 멀쩡했다.
- 무너질 때의 기록: 기울기 크기 6.5 → 23 → 74, 모듈 복원 학습 점수 0.68 → 0.10, 개인 경로 크기 0.63 → 4.8(E55에도 1.63으로 원래의 2.6배).

### 문제 3. 비교 기준이 함께 움직였다

- 안전장치는 "지금의 나(414개 다 켠 버전)"와 비교한다. 그런데 그 "나"가 같이 나빠지면 비교가 의미를 잃는다.
- 비유: 달리기 기록을 "어제의 나"와 비교하는데, 어제의 내가 다리를 다쳤다면 오늘 천천히 뛰어도 "기록 향상"이 된다.
- 증거(원래 NLL 값, 학습 평균): 볼륨 줄이기 단계에서 실제 사용 버전의 NLL은 0.590으로 그대로였는데, 비교 기준인 "다 켠 버전"의 NLL은 0.598(E42) → 0.620(E43) → 0.733(E44)으로 나빠졌다. 허용 폭이 약 0.006(1%)인데 기준이 0.14나 나빠져, 정규화 위반값이 -19.9(E52 계보도 -13.4)가 되었다.
- 코드상 위반값이 음수이면 벌점 기울기가 정확히 0이다. 즉 이 기간 NLL 안전장치는 부품 수를 붙잡는 힘을 거의 내지 못했다. 그 사이 남은 부품 후보가 285개 → 12개 → 10개로 급감했다.
- 해석의 한계: "다 켠 버전이 나빠진 이유가 연속 gate에 적응한 가중치 때문"이라는 설명은 가능하지만 아직 직접 검증하지 않았다.

### 문제 4. 안전장치가 전체 평균 점수만 봤다

- 안전장치는 전체 점수(NLL)만 확인하고, 개인차나 알츠하이머 점수는 보지 않았다.
- 전체 점수는 부품을 1/3이나 빼도 1% 안에서 거의 변하지 않을 만큼 둔하다. 그래서 절벽 직전까지 아무 신호가 없다가 한꺼번에 경보가 울린다.
- 비유: 반 평균만 보고, 특정 학생들 성적이 떨어지는 것은 못 보는 담임 선생님.
- 결과: SV7 모델에서 전체 점수는 좋아졌는데 개인차 점수는 0.78(E36) → 0.43(E55), 알츠하이머 점수는 0.90 → 0.68로 떨어졌다.
- 이후 "안전한 부품 조합 확인 완료" 표시(E49부터)도 같은 전체 점수 기준이라, 생물학적으로 안전하다는 뜻이 아니었다.

### 문제 5. GPU 개수에 따라 진행 속도가 달라졌다

- 온도(줄이는 속도를 조절하는 값)는 에폭(한 바퀴)마다, 부품 줄이기는 스텝(작은 걸음)마다 진행된다.
- GPU 4개 학습(SV7)은 한 바퀴에 걸음이 7,882번이고, GPU 6개(E52 계보)는 약 5,255번이다(1.5배 차이).
- 그래서 4-GPU 학습은 같은 바퀴 안에서 부품이 더 빨리 줄었다. 연습 단계 안에서 더 일찍 1% 선을 넘었고, 더 오래(약 1.4바퀴) 흔들렸다.
- 6-GPU에서 4-GPU로 옮길 때 모듈 복원 학습 걸음 수는 보정했지만, 부품 줄이기 일정은 보정하지 않았다.
- 걸음 수만 맞추면 끝나는 문제가 아니다. 한 걸음에 쓰는 세포 수(global batch)도 다르다(4-GPU 512개, 6-GPU 768개). Phase II에서는 4-GPU의 누적(accumulation)을 2 → 3으로 바꾸면 4 × 64 × 3 = 768개가 되어 global batch, 바퀴당 걸음 수(약 5,255), 바퀴당 세포 수가 동시에 맞는다. Phase I(누적 1)은 GPU당 batch를 96으로 늘려야 맞출 수 있다(메모리 확인 필요).

### 문제 6. E52도 같은 문제를 겪었다 (가볍게 지나갔을 뿐)

- E52 계보(GPU 6개, RLT 없음)도 똑같은 지점(처음 1% 선을 넘는 순간, E40)에서 흔들렸다.
- 다만 늦게 넘었고 흔들림도 작아서 1바퀴 만에 회복했다(개인 경로 크기 0.59 → 1.15 → 0.53으로 복귀).
- E52는 seed 1개, 학습 경로 1개의 결과라 재현성이 아직 확인되지 않았다. 같은 설정으로 다시 학습했을 때 비슷한 결과가 나올지는 모른다.
- E52의 부품 112개는 "컴퓨터가 찾아낸 꼭 필요한 최소 개수"가 아니다. 안전장치가 잠깐 꺼진 상태에서 나온 궤적 의존적 숫자다.

### 문제 7. E52의 구획(수상돌기 모사) 비선형 부품은 기여가 작았다

- 학습이 끝나도 설정값이 처음과 거의 같았다(예: 0.10 → 0.1007, 1.00 → 0.993).
- 2026-09-23 같은 조건 재측정에서 이 부품만 껐을 때(괄호는 donor bootstrap 95% 신뢰구간): 개인차 -0.002(-0.007 ~ +0.0004), 알츠하이머 -0.002(-0.010 ~ +0.006), 전체 점수 변화 0.00004. 세포 종류 24개 중 가장 크게 떨어진 경우도 -0.005였다.
- 신뢰구간이 0을 포함한다고 "효과 없음"이 증명되는 것은 아니다. 다만 구간 자체가 좁아서, 이 checkpoint와 이 지표에서는 개인차 점수 기준 약 0.007보다 큰 기여는 어렵다고 말할 수 있다.
- 한계: 이미 학습된 모델에서 부품을 끈 결과다. 이 부품 없이 처음부터 학습한 모델의 성능과는 다를 수 있다.
- 비유: "터보 엔진 장착"이라고 광고한 차에서 터보를 떼 봤더니 속도 차이가 거의 측정되지 않은 상황.
- 비선형 하위 부품의 기여가 작다는 것과 E52 모델 전체가 무의미하다는 것은 다르다. 모듈별 개인 보정 경로(module-local), 관측 병리 정보 경로, 개인 특성 경로의 가치는 별도로 남는다.
- 따라서 "구획 비선형성 덕분에 성능이 좋다"고 주장하지 않는다.

### 문제 8. RLT(계수 두 번 다듬기)는 효과가 거의 없게 설계돼 있었다

- 단독 원인일 가능성은 낮다: RLT가 켜진 뒤 22바퀴 동안(E16-E38) 학습은 안정적이었고, RLT가 없는 E52 계보도 같은 문제를 겪었다.
- 그러나 상호작용은 배제하지 못한다: RLT 파라미터도 연습 단계의 부품 선택 손실 경로에 들어 있고, 충격은 RLT가 있는 SV7에서 더 컸다. 다만 SV7은 GPU 수도 달라서 두 요인을 아직 분리할 수 없다.
- 그러나 도움이 된다는 증거도 없다: 다듬는 양이 설계상 최대 10% 이내로 묶여 있어, 0번/1번/2번 다듬어도 결과가 거의 같았다(E50에서 차이 0.0001 수준).
- RLT가 없는 같은 조건 대조 학습도 아직 없다.

### 문제 9. Dream(두 번째 다듬기 건너뛰기)은 이득이 작을 가능성이 크다 (실제 시간 측정 필요)

- 계산량(FLOP)으로 추정하면 두 번째 다듬기는 디코더 핵심 계산의 약 2%다. 43%를 건너뛰어도 계산량 기준 1% 미만을 아끼는 셈이다.
- 이것은 추정일 뿐이다. 작은 연산은 GPU 실행 준비 비용 때문에 실제 시간 비중이 계산량 비중보다 클 수도 있다. 판단 정책과 점검(probe) 비용도 있다. 따라서 실제 wall-clock 측정 전에는 이득 여부를 단정할 수 없다.
- 두 번째 다듬기가 원래 거의 효과가 없어서, "건너뛰어도 품질 유지"는 당연히 통과한다. 그래서 그 결과만으로는 의미가 없다.
- 현재 SV6 Dream 학습도 같은 부품 줄이기 설정을 쓰므로, E37 이후 같은 문제를 겪을 가능성이 크다.

### 참고. 병 진행 순서 점수 해석 주의

- 모델이 만든 모듈 값으로 병 진행 순서(ADNC)를 맞히는 점수: 실제 데이터 0.31, E52 0.29, SV7 E36 0.84.
- E52는 실제 데이터와 비슷하다. E36은 실제 데이터보다 훨씬 높은데, 입력받은 병리 검사 결과를 출력에 과하게 새겨 넣었을 가능성이 있다(해석이며 아직 확인되지 않음). 높다고 무조건 좋은 것이 아니다.

## 3. 고쳐야 할 점

1. 연습은 연습만: 연습 단계에서는 부품 중요도만 배우고, 모델 실력(가중치)은 건드리지 않게 막는다.
2. 벌점과 허용 기준을 분리: (가) 학습 중 벌점은 minibatch 잡음을 고려해 평균을 낸 뒤 적용하고 상한을 둔다. (나) 부품 조합을 받아들일지 판단하는 허용 기준은 표준오차만으로 정하지 않는다. 표준오차가 크면 큰 성능 저하까지 허용되기 때문이다. 허용 가능한 생물학적 저하량을 먼저 정하고(예: 개인차 점수 -0.02), 신뢰구간 하한이 그 범위 안에 들어올 때만 받아들인다.
3. 기준은 고정: 가장 좋았던 시점(예: E36)을 사진 찍어 두고 그 사진과 비교한다. "지금의 나"와 비교하지 않는다.
4. 생물학 점수도 안전장치에: 개인차 복원, 알츠하이머 복원, 세포 종류별 최하위 성적, 정보 누출을 검사하고, 나빠지면 되돌린다.
5. 계단식으로 천천히: 조금 줄이기 → 적응할 시간 → 검사 → 통과하면 다음. 한 바퀴에 줄일 수 있는 양에 상한을 둔다.
6. 시간표는 걸음 수 기준: 온도와 줄이기 일정을 스텝 단위로 정해, GPU 개수와 상관없이 같은 속도로 진행한다.
7. 결과는 곡선으로: 숫자 하나 대신 "부품 수 대 생물학 점수" 그래프로 보여준다.
8. 구획 부품: 현재 위치에서는 효과가 없으므로 위치를 옮기거나 제거한다.
9. RLT는 보류: 효과를 주장하지 않고, 부품 줄이기 문제를 먼저 고친 뒤에 비교한다.

## 4. 아직 확인하지 않은 것 (가설 단계)

- 문제 1-2가 E39 붕괴의 원인이라는 것은 시점, 코드 경로, 크기 계산, 다른 계보 재현으로 강하게 뒷받침되지만, 인과 증명은 아직 없다.
- 중요한 빈칸: "부품을 실제로 끄기 전에 이미 생물학 점수가 무너졌다"는 주장은 지금까지 학습 기록의 NLL과 학습 쪽 모듈 복원 점수에 근거한다. 검증 세트의 개인차·알츠하이머 점수는 E39/E40에서 아직 재지 않았다.
- 확인 방법 1: E37-E41 checkpoint 사후 채점(학습 없음, checkpoint당 약 10-20분). 위 빈칸을 가장 싸게 채운다.
- 확인 방법 2: E38/E39에서 손실별 기울기 측정(학습 없음).
- 확인 방법 3: E38에서 "원래 코드" 대 "연습 단계에서 부품 중요도만 학습" 짧은 재실행 비교.
- GPU 개수 때문에 속도가 달라졌다는 설명(문제 5)도 가설이다.
- E52 대 SV7 E36: 개인차는 E52가 +0.056(-0.010 ~ +0.128), 알츠하이머는 E36이 +0.036(-0.189 ~ +0.161)으로, validation donor 16명으로는 우열이 명확하지 않다(동등성이 입증된 것도 아니다). E52 대 E55는 개인차 +0.41(0.22 ~ 0.68)로 E52 우세 근거가 강하다.
- 이 신뢰구간은 해당 checkpoint와 validation donor를 조건으로 한 불확실성이다. 학습 seed, checkpoint 선택, 새 cohort의 불확실성은 포함하지 않는다.
- E52를 논문 메인으로 두는 이유는 "E36보다 통계적으로 우수해서"가 아니라, 기존 분석의 완성도와 검증 이력까지 고려한 선택이다.
